# Lativia

Lativia 是面向中文用户的墨西哥办事与咨询服务平台。

当前服务重点包括墨西哥 RFC、e.firma、SAT、INM、
Cetesdirecto 等官方流程的中文说明、资料准备与办理协助。

## Website

https://lativiaglobal.com

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Stripe
- Mercado Pago
- Resend
